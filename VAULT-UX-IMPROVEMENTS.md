# C3 — Vial Vault UX improvements

- Rebuilt `vault.html` around a clearly labeled, request-based documentation form, a four-step explanation of follow-up, lot-matching guidance, and an educational CoA field guide. Removed unsupported “most lots” availability and future-archive promises, unlock imagery, and language implying verified documents or results.
- Added accessible field labels/helpers; required compound, lot, and reply email; input limits; editable prefill notices; and canonical-name matching for existing product-name, short-name, and slug links. Existing `product`, `lot`, `email`, and `#request` links remain supported. Prefill does not imply document availability.
- `js/vault.js` shows **Request received** only after an explicit `{ ok: true }` acknowledgement from the existing API helper. It blocks duplicate submission while pending, preserves fields after errors, focuses the confirmation/error, and supports a fresh request for another lot. Missing scripts, failed requests, and malformed responses cannot show a receipt.
- Email fallback prepares an editable draft containing the entered details and clearly requires the user to send it. The no-JavaScript form stays disabled with email instructions. New requests are no longer copied into browser localStorage. Support remains `hello@asktrusthub.com`.
- Added responsive dark styling, mobile navigation, and prominent How to Read a CoA, HPLC/MS, purity, storage, and quality links. Updated the service-worker cache and asset list. The existing API and email-delivery configuration are unchanged.
- Validation: Chromium checks passed for 320–1440 px layouts, desktop/mobile and success/error accessibility, product-page and alias prefills, safe query handling, validation, draft contents, API payload, pending/duplicate protection, success/reset, server/network/malformed/missing-helper failures, and no-JavaScript behavior. Screenshots reviewed; local links, syntax, and diff checks passed. API responses were intercepted in tests; no test emails were sent and production email delivery was not revalidated.
